# tools/ — release verification, export & CI support

Python 3 stdlib + POSIX shell; environment-isolation regressions also execute
Node. Default `verify.sh` is offline and never boots live DSH. Explicit vanilla
acceptance and `smoke-clean-source.sh --plugins` use public SDK dependencies,
private homes/workspaces and only self-owned processes.

| Tool | Purpose |
|------|---------|
| `verify.sh` | Single verification entrypoint: scan → assets → binaries → gate status → SBOM → export dry-run → tools tests. `VERIFY PASS` means these checks passed; it does NOT close the publication gates (reported separately as advisory). |
| `scan-secrets.py` | Secret/PII/path/device-identifier scan. Reports paths + counts only — never secret values, never cleans files. Scans archive members too (`--archive` for one built artifact). Rejects legacy Cappi restores, tree-escaping symlinks, and staged build-cache entries (`.gradle-home` content is scan-excluded as ignored cache, but a staged/tracked cache entry or one packed in an archive fails as `staged-cache`). Licensed `cappi-original` GIFs pass only when manifest-authorized + hash-verified against `characters/cappi-original/provenance.json`; unknown or mismatched files there fail as `untracked-asset`. |
| `check-license-gate.py` | Publication gate: BLOCKS while the legacy Cappi dir holds restores, the licensed `cappi-original` hash inventory is unverified (grant + 25-file sha256 provenance + mirrors + registry entry), or the recorded owner approvals are missing. Project-code and imported voice-plugin source are owner-approved Apache-2.0 (2026-09-27; closed). LOCAL candidates still build. Confirmation is an owner-approval record (license id + date); no personal name/email/handle is required or wanted. |
| `export-source.sh` | Reproducible allowlist export (`ALLOWLIST.txt`): sorted, fixed mtime, uid/gid 0, deterministic gzip (`GZIP=-n` on the GNU tar path), `.sha256` sidecar into gitignored `dist/`. Output confined to `dist/` (`--out` elsewhere refused; newlines/symlinks refused). Refuses secrets, escaping symlinks, and any licensed-Cappi file that is not manifest-authorized + hash-verified. GNU-tar flag is `--sort=name` (portable); temp files use `XXXXXX` templates (BSD + GNU mktemp). |
| `release-bundle.sh` | Bundle + checksums. Refuses without `--local` while gates are open; `--local` writes sidecar `GATE-STATUS.txt`, SBOM JSON, and `LOCAL-MANIFEST.txt` into `dist/` (sidecars, not embedded in the tarball). Scans the source tree AND the built archive; any finding refuses the bundle. `--local --artifacts` adds a separate local-only bundle — generic-signed DEBUG/DEV fresh-install APK plus optional standard unsigned release (not R8-minified; requires owner signing), and installable plugin `.tgz` packs (isolated local `npm pack --ignore-scripts --offline` from the already-built packages; lifecycle scripts never run, nothing is installed/deployed, packs land in gitignored `dist/`) — with its own checksums, artifact SBOM, and recursive hygiene scan of nested members (no signing key generated; `.sha256` sidecars are integrity hashes, not release signatures — never imply a signed release). |
| `sbom.py` | Dependency/asset inventory with upstream metadata; model weights are external references (license links + checksum docs), never bundled. Third-party dependencies retain their upstream metadata licensing (NOASSERTION with links — never blanket-marked). No hashes fabricated. |
| `inspect-binaries.py` | Metadata (size, SHA-256, type, archive members) for shipped binaries — the required Gradle wrapper jar plus the hash-verified licensed Cappi GIF inventory (provenance sha256 + size + mirror + gif-kind checks). Nothing is executed. |
| `inspect-artifacts.py` | Hygiene + artifact SBOM for the `--artifacts` bundle: bounded recursive scan of nested archives (APK/zip/tgz, with depth/count/expanded-size limits), refuses unsafe layouts and symlink escapes, local absolute paths/sourcemaps, credential values, secret-named and staged-cache members. Oversize/unscannable members are rejected, never blessed on a head sample. Placeholder exemptions are match-local only. DEX/arsc/res/assets carriers get printable-string extraction; opaque third-party binary (native .so, images, signatures) is listed + hashed, never string-mined (see the module policy note). CAFEBABE JVM/Mach-O collision is resolved by bounded JVM structure/constant-pool/class-reference/EOF checks, not filename exemptions; JVM strings remain hygiene-scanned (not semantic bytecode/virus validation). Mach-O is accepted only at exact `package/resources/bin/watch-asr`, with mandatory source/plist/binary manifest SHA256 and header-parsed architecture equality; legacy/suffix-collision/unlisted paths fail. Nothing is executed; macOS acceptance separately verifies the actual ad-hoc signature/minimum OS. Android DEBUG certificate metadata is public/generic, not an opaque user identity. |
| `inspect-apk.py` | Calls Android build-tools `apksigner verify --print-certs`; requires exactly the standard Android Debug certificate subject for the DEBUG/DEV fresh-install output. Records public cert SHA256 and APK SHA256, never reads/copies a keystore. Not a production signing or original-watch upgrade claim. |
| `lib/native-proof.py` | Rejects stale native snapshots, mismatched streams/utterances/text, incomplete new turns and unrelated TTS speechIds; reports only counts/sequences, never transcript contents. |
| `lib/callback-proof.py` | Requires a fresh SDK turn/user/model tool-call, one matching durable result and completion; approval additionally correlates exact asked/decided audit. Idle/manual callback fakes and stale results fail. |
| `lib/snapshot-plugin.py` | Full-byte pre/post source+lib snapshot stability gate before npm pack; refuses in-flight changes and symlinks, excludes dependency/runtime caches. |
| `validate-assets.py` | Registry↔pack↔watch-mirror consistency, license fields, licensed-Cappi hash-inventory verification (provenance sha256 + clips cross-check + mirrors + registry entry), legacy cappi-dir gate, protocol fixtures. |
| `installer-dryrun.sh` | Plan-mode runs of bridge + plugin installers under an isolated temp HOME (CI; `--bridge-only` for bridge scripts). |
| `test-vanilla-install.sh` | Independent vanilla acceptance (P-owned): `--doctor` prints prereqs + guided steps (no boot); `--probe` (default) installs a synthetic probe bundle via the official DSH JS entry and boots keyless on an ephemeral port (passes without H/V); `--full` packs dsh-watch + dsh-live-voice FROM SOURCE plus a temp-only fixture LLM plugin (official `ctx.llm.registerAdapter`, synthetic `fixture-local` provider — never shipped), installs via the official CLI, and drives the real pairing/device/mic/SSE wire plus HOST_LLM routing (real `sessionController` create/prompt/page/follow: synthetic user phrase → durable user record → fixture assistant echo), binding-vs-real-session + cappi 409/200 gates, revoke-then-401, and Mach-O header-parsed manifest truth. Verdicts: FULL PASS (exit 0) only when routing AND native legs are green; ROUTING_PASS (exit 3) when routing is proven but a native leg stays pending (fake-ASR routing is labelled, never a native claim); `--require-native` turns pending native legs into exit 1; `--node-bin=/absolute/path` selects the real Node for ALL CLI/boot/pnpm descendants; default non-22 runs execute a complete private Node22 child leg (not a version probe) before matrix PASS. `--skip-node22` explicitly limits support evidence to the printed current runtime; unavailable Node22 means matrix PENDING. Native evidence correlates actual final/utterance → new durable user after cursor → new completed assistant → production speechId/audio; registered SDK Cappi execution proves dance state/SSE. Full acceptance also requires real no-speech/ACK0/no-new-prompt and repeated RECORD readiness after EOF/no-speech without setup/synthesis, plus scoped mic-cancel/idempotence/retired-ID refusal. Real model-requested SDK callbacks require fresh turn/user/tool-call/result/completion, not idle fakes. All modes apply an environment allowlist before Node, use private homes/empty workspaces (600/700), bind ephemeral ports only (never 3083/8787/8789), and reap only self-owned PIDs. The full fixture privately disables the default external adapter; SDK registered/routable metadata alone does not mean credentials exist. Published default configuration remains unchanged. |
| `smoke-clean-source.sh` | Extract a `--local` source archive to a fresh private root, re-run bridge/tools verification, prove no symlinks/absolute links back to the working tree or install. Default is offline/no plugin installs. Explicit `--plugins` performs frozen published-SDK installs, compiles the native helper FROM EXPORTED Swift/plist on macOS, then both full plugin TS/client/build/test suites. Voice tests serialize ALL files at unchanged assertions/default deadlines, matching CI; no filters/skips. `--keep-tmp` retains extracted proof roots. Never runs Gradle or deploys. |
| `lib/release_common.py` | Shared allowlist / filename / placeholder / staged-cache rules, plus the licensed-Cappi inventory helpers (`cappi_inventory`, `verify_cappi_original`, `sha256_file`) used by the gate, scanner, asset validation, binary inspection, and export backstop. |
| `tests/` | `unittest` suite; fixtures are generated at runtime in temp dirs (no secrets in the repo). Includes exact plugin `exports`/`files` manifest expectations and nested-archive inspector regressions. |
| `ALLOWLIST.txt` | Curated source allowlist. Explicit `file:` entries win over `except:` (gate README, wrapper jar, root/plugin LICENSE + NOTICE companions, licensed-Cappi manifests). The 25 licensed GIFs (+ mirrors) ship via the `characters/` + `watch-app/` dir rules under the export hash backstop — only manifest-authorized bytes. Ships CI (`.github/workflows/ci.yml`) and the watch companion skill (`plugins/dsh-watch/SKILL.md`); built `lib/` and pack `.tgz` stay out (source-only). |
| `VERSION` | Bundle label `0.3.0-rc0` (mirrors root `VERSION`; all components — `watch-app`, both plugins — are at `0.3.0-rc0`). |

## Versioning

`0.3.0-rc0` labels the release bundle/candidate, and all components are
at `0.3.0-rc0` (`watch-app` `versionName`, both plugin `package.json`
versions). Template/example sources (e.g. `characters/example-pack/`)
carry their own in-pack copyright/license metadata; no project-wide
grant is invented (see `LICENSE-DECISION.md`).
